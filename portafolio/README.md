# Ana Fiorella Arduino De Michielis — Portfolio Personal

Este repositorio contiene el código fuente de mi portafolio profesional como Full Stack Developer, enfocado en el diseño de interfaces minimalistas y arquitecturas backend robustas.

## 📌 Enfoque Técnico y de Diseño

El sitio ha sido desarrollado evitando intencionalmente los frameworks pesados y las plantillas genéricas. Se prioriza el rendimiento, la accesibilidad y una estética "brutalista refinada" que refleja el rigor de la ingeniería de software.

*   **Arquitectura:** Single-file deployment (HTML puro).
*   **Estilos:** Tailwind CSS (vía CDN) con configuración de tema personalizada inyectada para mantener el aislamiento del diseño.
*   **Tipografía:** Playfair Display (Serif) y Space Mono (Monospace) para generar contraste entre autoridad y entorno técnico.

## 🚀 Despliegue

El sitio está desplegado de forma continua y automatizada utilizando **GitHub Pages**. 
Cualquier push a la rama `main` actualiza el entorno de producción inmediatamente.

**URL de producción:** [https://tu-usuario.github.io](https://tu-usuario.github.io)

## 🛠️ Stack Principal del Perfil

*   **Backend:** Node.js, NestJS, Java, Express.
*   **Bases de Datos:** PostgreSQL.
*   **Mensajería / Infra:** RabbitMQ, Linux, Cisco (OSPF/BGP).
*   **Frontend:** React, TypeScript.
