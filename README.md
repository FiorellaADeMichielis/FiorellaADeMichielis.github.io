## 🎨 Características Técnicas del Portafolio

- **Modo Oscuro Puro:** Esquema cromático de alto contraste (13:1) en slate nocturno (`#0b1120`, `#131d2e`, `#1e293b`) con acentos cyan técnicos luminosos.
- **Selector de Idioma Intuitivo:** Control segmentado (pill switch) con ambas opciones (`ES` / `EN`) visibles, estado activo iluminado y soporte i18n reactivo.
- **Visor Modal (Lightbox):** Modal interactivo accesible para visualización de capturas en pantalla completa sin recortes (`object-contain`) con control de teclado (`Escape`, flechas).
- **Tipografía:** Exclusivamente **Inter** para garantizar nitidez y legibilidad profesional.
- **Despliegue Continuo:** Configurado con GitHub Actions para despliegue automatizado en GitHub Pages.

## ⚙️ Desarrollo Local

```bash
# Clonar el repositorio
git clone https://github.com/FiorellaADeMichielis/FiorellaADeMichielis.github.io.git

# Entrar al directorio del portafolio
cd FiorellaADeMichielis.github.io/portafolio

# Instalar dependencias
npm install

# Iniciar entorno de desarrollo
npm run dev

# Compilar para producción
npm run build

# Ejecutar linter
npm run lint
```
